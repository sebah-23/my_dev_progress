# 🎬 Netflix Clone

A responsive Netflix-inspired movie streaming web application built with React, Tailwind CSS, and the TMDB API.

The application fetches real-time movie and TV show data from TMDB and displays it in a modern streaming-platform interface with a dynamic hero section, categorized movie sections, horizontal sliders, search interface, and interactive movie cards.

## ✨ Features

- 🎬 static movie and TV show data
- 🔥 Trending movies
- ⭐ Popular movies
- 🎭 Movies organized by genre
- 🎞️ Dynamic hero section
- 🔄 Random featured movie on page refresh
- ↔️ Horizontal movie sliders
- 🖱️ Movie card hover effects
- 📱 Responsive design
- 🎨 Netflix-inspired user interface


## 🛠️ Technologies

- **React.js**
- **JavaScript**
- **Tailwind CSS**
- **TMDB API**
- **Vite**
- **Git & GitHub**
