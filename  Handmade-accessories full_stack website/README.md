# Handmade Accessories

A full-stack handmade accessories e-commerce website built with **React, Node.js, Express.js, and MySQL**.

## 📖 About the Project

This project is a modern full-stack rebuild of my original **Handmade Accessories** website.

The first version was built using:

* HTML
* CSS
* JavaScript
* PHP

This new version is being rebuilt with **React, Vite, Tailwind CSS, Node.js, Express.js, and MySQL** to improve the original project and strengthen my full-stack development skills.

The project covers both the customer-facing frontend and the backend system responsible for managing products, orders, custom orders, and contact messages.
